## About the Project

This is my personal developer portfolio, built to introduce myself, showcase my technical skills, present my projects, and make it easy for people to contact me.

I'm continuously improving this project as I grow in software engineering and web development.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- EmailJS
- Git & GitHub

## Features

- Modern portfolio design
- Dark and light theme toggle
- Responsive navigation
- About me section
- Skills and technologies showcase
- Featured projects section
- Working EmailJS contact form
- Dynamic copyright year

farman-portfolio/

## Run Locally

1. Clone this repository:

```bash
git clone https://github.com/junejofarman/farman-portfolio.git
```

2. Open the project folder:

```bash
cd farman-portfolio
```

3. Open `index.html` in your browser.

No build tools are required.
