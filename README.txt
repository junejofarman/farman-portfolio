# Farman Junejo — Portfolio redesign

## Run locally
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server, or open it in your browser.
4. Keep an internet connection available for Google Fonts and the EmailJS browser SDK.

## EmailJS
The existing Service ID, Template ID, and Public Key have been carried forward from the supplied project so the form can continue using the same EmailJS configuration. Test the form after opening this redesign. This project uses only the browser-safe Public Key; never add an EmailJS Private Key to frontend JavaScript.

## Before publishing
- Replace planned project ideas with real projects when they're built.
- Update project links to your actual repositories or live demos; don't claim placeholder links as your work.
- Check the contact form and theme toggle on mobile and desktop.
- The theme toggle currently works for the current page session; it does not save a preference after refresh.
